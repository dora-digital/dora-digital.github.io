# Project Chic v1.0

**Created by:** Dorathy Godwin Ogbuh  
**Release date:** 24 July 2026  
**Version:** 1.0

## About

Project Chic is a desktop productivity companion inspired by an Instagram desktop companion concept and designed and implemented from scratch using Python and PySide6.

It was created as a personal software engineering project to explore desktop application development, object-oriented programming, event-driven programming, state management, and user interaction design.

## Features

• Activity detection  
• Working state  
• Thinking state  
• Idle state  
• Sleeping state  
• Morning greeting  
• Breakfast schedule  
• Welcome back greeting  
• Hydration reminders  
• End-of-day reminder  
• Focus sessions  
• Celebration animations  
• Interactive click behaviour  
• State-based behaviour engine  

## Technologies

• Python 3.14  
• PySide6  
• PyInstaller  

## Personal Note

Project Chic began as an idea inspired by something I saw on Instagram. Rather than simply admiring it, I challenged myself to design and build my own version from scratch.

This project marks my first complete desktop application and represents an important milestone in my software development journey.
